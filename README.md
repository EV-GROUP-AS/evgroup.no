# EV Group website

Static website for EV Group, hosted with GitHub Pages.

## Structure

- `assets/css/` for stylesheets
- `assets/images/` for images
- `assets/js/` for browser-side JavaScript
- `.github/workflows/deploy-pages.yml` for GitHub Pages deployment

## Publishing

Pushes to `main` deploy the repository root to GitHub Pages. The site entry point
will be `index.html` when the page is added.
