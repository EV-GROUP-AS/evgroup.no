# EV Group website

React-powered static website for EV Group, hosted with GitHub Pages.

## Structure

- `assets/css/styles.css` for the responsive site styles
- `assets/js/app.js` for the React application
- `assets/images/` for future image assets
- `.github/workflows/deploy-pages.yml` for GitHub Pages deployment

## Publishing

Pushes to `main` deploy the repository root to GitHub Pages. The site entry point
is `index.html`.
